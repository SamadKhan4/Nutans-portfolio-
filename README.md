# Nutan Upare — Portfolio

A responsive React + JSX portfolio styled with Tailwind CSS v4 and custom CSS. Content and the hero illustration are sourced from the supplied portfolio PDF.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).

## Production

```sh
npm run build
npm run preview
```

The static production website is generated in `dist/`.

## Update content

Edit project data, services, and section content in `src/main.jsx`. Styling is in `src/styles.css`. Replace `public/portfolio.pdf` to update the downloadable portfolio.

Project filters and accessible case-study dialogs run locally in the browser. Contact links open the visitor's email, phone, or LinkedIn application; there is no server or form backend.
